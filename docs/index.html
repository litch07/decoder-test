Extension Architecture

Augment Portals Directly in Your Browser

The companion Chrome Extension automatically detects cryptic course codes on university web pages and replaces confusion with instant clarity.

⚡

Universal Detection

Scans UCAM advising slips, eLMS dashboards, and even SVG exam schedule charts to decode codes on the fly.

🎨

3 Adaptive Display Modes

Switch seamlessly between Highlight (interactive card on hover), Tooltip (zero layout change), and Inline (course titles in parentheses).

🔒

Per-Site Permissions

Operates under strict least-privilege optional host permissions. Only inspects webpages you explicitly authorize via the popup.

🛡️

Zero-innerHTML Security

Purged entirely of unsafe DOM injection methods. Every element is constructed through safe browser programmatic APIs.

💾

100% Offline Database

All 315+ courses and user overrides live locally in chrome.storage.local. Zero telemetry, zero external trackers.

🔄

Contextual Export & Diff Import

Export filtered course sets, drag-and-drop JSON catalog backups, and preview line-by-line diffs before committing changes.

Quick Setup Instructions for Manual ZIP:

  1. Download and extract uiu-course-code-decoder-v2.0.0.zip.
  2. Open chrome://extensions in your browser and enable Developer mode in the top-right corner.
  3. Click Load unpacked and select the extracted folder.
  4. Pin the extension and navigate to UCAM (ucam.uiu.ac.bd) to start decoding!
