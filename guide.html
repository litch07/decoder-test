🚀

Getting Started & How It Works

Automatic detection, zero friction, and high compatibility

Once installed, the extension runs automatically in the background on allowed domains (such as ucam.uiu.ac.bd and lms.uiu.ac.bd). When you open any page:

  • 1

    Automatic DOM Scanning

    The extension parses the page for UIU course code patterns (e.g., CSE 1111, MATH 1151, ENG 1011, ACT 2111) using an efficient MutationObserver that handles single-page apps (SPAs) and dynamic table updates without slowing down your browser.

  • 2

    Instant In-Place Enhancement

    Every identified code is transformed according to your selected display mode. Hovering reveals course details immediately.

  • 3

    SVG & Chart Overlay Integration

    On pages with grade distribution or attendance charts, course codes rendered inside SVGs are detected, and rich tooltips appear smoothly using an external layout-safe floating overlay.

💡
100% Privacy Focused: All course decoding and local changes happen right inside your browser. No browsing data, student IDs, or grades are ever transmitted to any external server.
🎨

Display Modes & Tooltip Settings

Customize how course codes appear on your screen

In the extension popup under Display Mode, you can choose the presentation that best fits your workflow:

✨ Highlight Mode

Wraps course codes in a subtle warm yellow badge with an underline. Ideal when scanning long course lists or preregistration schedules so codes instantly stand out.

💬 Tooltip Mode

Subtly underlines the course code. Keeps the page layout ultra-clean while providing instant full-detail popups when you move your cursor over any code.

✏️ Inline Mode

Directly inserts the full course title in parentheses right next to the code (e.g., CSE 1111 (Structured Programming Language)). Great for reading syllabi without hovering.

Tooltip Metadata Toggles

In the extension popup, you can customize what additional information appears inside the hover tooltip:

  • 📅

    Show Exam Day & Slot

    Displays the scheduled final exam day (e.g., Day 4) and exam time slot (e.g., T2) so you can check for exam conflicts while advising courses.

  • 🔗

    Show Prerequisites

    Lists required prerequisite courses (e.g., CSE 1111, MATH 1151) with clickable badge indicators.

Allowed Domains & Site Management

Control exactly where the extension is active

By default, the extension is configured to work on official UIU domains:

  • ucam.uiu.ac.bd — UIU Unified Class Assessment & Management Portal
  • lms.uiu.ac.bd — UIU Moodle E-Learning Portal
  • *.uiu.ac.bd — Any official UIU subdomain (wildcard)

Adding New Sites or Wildcards

You can add any custom domain (e.g., localhost or a departmental staging site) by typing it into the Allowed Domains input in the popup and clicking Add. Wildcard patterns like *.uiu.ac.bd are fully supported and will match any subdomains automatically.

⚡
Quick Site Toggle: You can temporarily disable the extension on any active website by unchecking "Enable on this site" in the popup without removing the domain from your permanent allowlist.

Course Database Manager

Search, customize, and edit course information locally

Clicking Manage Course Database opens the sliding catalog browser with real-time search across hundreds of course offerings.

Understanding Course Origin Labels

Every course in your database displays an origin tag indicating where it came from:

Official

Pre-packaged courses provided directly by the verified UIU catalog and GitHub database.

User Added

Custom courses you created or imported from your own custom JSON schedules.

Edited

Official courses where you customized the title, exam slot, or prerequisites locally.

Editing a Course

Clicking any course row opens the Course Details panel. Here you can edit the full title, update exam day / slot, and change prerequisite codes. All edits are saved instantly in your browser's persistent storage.

🗑️

Trash Bin & Deletion Lifecycle

Accidentally removed a course? Here's how restoration works

To keep your data safe, deleting a course follows a gentle two-phase lifecycle:

  • 1

    Soft Delete (Moved to Trash Bin)

    When you delete a course from the Course Details panel, it is moved to the Trash Bin. It will no longer highlight or decode on web pages, but it can be restored with a single click at any time.

  • 2

    1-Click Restoration

    Open the Trash Bin (trash can icon in Course Manager header) and click Restore on any course, or click Restore All to recover everything in the trash.

  • 3

    Empty Trash (Permanent Delete)

    Clicking Empty Trash permanently removes deleted courses from your local memory.

GitHub Catalog Sync & Factory Reset

Stay up to date with new trimester courses without reinstalling

Sync Course Database

Clicking Sync Course Database connects to the official community GitHub repository to pull new course codes, updated exam schedules, and prerequisite revisions submitted by contributors.

Understanding the Sync Diff Card

After syncing, a breakdown card appears showing:

  • +X Added: Brand new course offerings added to the catalog.
  • X Updated: Courses whose titles or exam schedules were revised.
  • X Removed: Obsolete courses discontinued in the latest trimester.

You can click on "+X more" in the diff preview to expand and inspect the exact list of changed courses anytime.

Reset Official Courses to Default

If you ever want a clean slate or want to undo all deletions of official courses, click Reset Official Courses to Default. This restores all original bundled courses while safely keeping all your custom user-added courses intact!

Bulk JSON Import Specification

Add custom department courses or export shared course packs

Under Add / Import Courses, you can paste multiple custom courses formatted as JSON. The extension validates the syntax and seamlessly merges them into your catalog. 

{
  "CSE 1111": {
    "name": "Structured Programming Language",
    "examDay": "Day 4",
    "examSlot": "T2",
    "prerequisites": []
  },
  "CSE 2215": {
    "name": "Data Structures and Algorithms",
    "examDay": "Day 2",
    "examSlot": "T1",
    "prerequisites": ["CSE 1111"]
  }
}
💡
Simple String Format Also Supported: If you only need the course title, you can write: "CSE 1111": "Structured Programming Language".
